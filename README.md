# Gerador de Laudos v2

Versão revisada com até 5 equipamentos por OS, uma folha A4 por equipamento, relatório final, peças estruturadas e totais automáticos.

## Atenção
Esta versão usa uma nova chave de armazenamento (`gerador_laudos_v2`). Backups da versão 1 não são importados automaticamente.

## GitHub Pages
Envie os arquivos para a branch `main`. Em Settings > Pages, selecione GitHub Actions.
